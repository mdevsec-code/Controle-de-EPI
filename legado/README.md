# Legado (referência funcional e visual)

Protótipo original que define o comportamento e a identidade da ENGENOVA usados na refatoração.

- `index.html` — protótipo navegável (HTML/JS, dados fictícios): login, home, scanner, busca de
  funcionário, seleção de EPI, quantidade, motivo, assinatura, sucesso e histórico.
- `*.png` — capturas das telas de referência.

Não faz parte do sistema em produção. O scaffold React vazio, os scripts de restyle e a landing de
apresentação (`index_final.html`, de onde foi extraído `apps/web/src/assets/engenova-logo.png`)
foram removidos na refatoração e continuam disponíveis no histórico do git (commit `c4a02b4`).
